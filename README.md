# Sistem Laporan Kerusakan Barang & Fasilitas Sekolah

Aplikasi penunjang produktivitas berbasis Android untuk memudahkan siswa atau warga sekolah dalam melaporkan kerusakan barang atau fasilitas secara cepat[cite: 1].

## 🛠️ Spesifikasi & Fitur Minimum Tugas Akhir:
- **Navigasi (3 Layar)**[cite: 1]:
  - `Screen Login`: Autentikasi pengguna/siswa.
  - `Dashboard`: Menu utama melihat status laporan dan riwayat.
  - `Screen Input Data`: Formulir untuk mengirim laporan kerusakan baru.
- **Sensor / Hardware**: Menggunakan **Kamera** (untuk mengambil foto bukti barang rusak) atau **GPS/Lokasi** (untuk mendeteksi titik lokasi fasilitas yang rusak)[cite: 1].
- **Cloud / Backend**: Terhubung secara *real-time* menggunakan **Firebase Realtime Database**[cite: 1].
